Case studies

01

Joyka

Mobile app with short guided meditations for people under stress.

Product OwneriOSDeveloper and designer on the team
ProblemReduce stress in 4–5 minutes.
Result8 scenarios, 3 voices, streak statistics. iOS app.
Problem
People under stress need a fast practice. Long generic courses do not fit the “right now” situation.
Role
Product Owner. Market research, audience analysis, questionnaire survey. Requirements for the developer and the designer. They wrote the code and drew the design.
What I did
  1. Researched the market and the audience, ran a questionnaire survey.
  2. Defined 8 situations of 4–5 minutes: sleep, tension, appetite, decisions and others.
  3. Specified the sound setup: metronome, nature sounds, 432 Hz music, 3 voices, separate volume per layer.
  4. Added retention: daily reminder, day streak, statistics per meditation.
Result
8scenarios
3voices
3sound layers
4–5 minper session
  • Finished iOS app with personal statistics and streaks.
Tools
Questionnaire surveyMarket researchAudience analysis
Metrics
MetricDefinitionTarget
Frequencyprimary metricCompleted sessions per active user per week3
ActivationNew users who finish a first session on install day60%
Completion rateCompleted sessions / started sessions70%
Day-7 retentionUsers who return on day 720%

Targets are benchmarks I would set for the product. They are not measured results.

Takeaway
I would build analytics events into the first release. Without them it is unclear which scenarios bring people back.
02

Growing City

Browser game: one-click match, bots, lobby by link.

Product OwnerProject ManagerWebFull cycle
ProblemPlay without waiting for friends.
Result50+ players, 3 languages, match analytics, indexed by Google and Yandex.
Problem
A board game needs company. Gathering people at one moment is hard.
Role
Product Owner and Project Manager in one person: idea, rules, balance, priorities, releases, analytics. Code written with Claude and Cursor.
What I did
  1. “Quick game”: a match starts at once, free seats are filled by 6 bot characters.
  2. Lobby by link with a PIN code, 3 match-length modes.
  3. Card balance: two iterations. Tutorial, chat with reactions, player kick.
  4. Interface in Russian, English and Spanish.
  5. Fixed connection blocking, player disconnects and the mobile layout.
Result
50+players
2search engines: site verified
1admin panel with match analytics
  • Own match analytics.
  • Launched on its own domain with SSL.
  • Hosting is not renewed, there is no public link now.

Week12

Goal planning service based on the “12 Week Year” method.

Product OwnerProject ManagerWebFirst product
ProblemConnect a yearly goal with weekly tasks.
Result4 goal levels, life wheel with 8 areas, retrospectives. Project closed.
Problem
A big goal gets lost without a link to the actions of the week.
Role
Product Owner and Project Manager. Moved a consulting goal-achievement method into a service.
What I did
  1. Goal hierarchy: vector, yearly goals, season goals, tasks.
  2. Dashboard: cycle progress, weekly focus, 12-week map.
  3. Life wheel with 8 areas, weekly retrospectives, reward for a finished season.
  4. Onboarding with self-assessment, email reminders, admin panel.
  5. Russian personal data law (152-FZ): cookie consent, data processing policy.
Result
4goal levels
12weeks per cycle
8life areas
1full user path
  • Working path from sign-up to a finished season.
  • Protection: login attempt limit for the admin panel, row-level access in the database.

04

Own Your Future

Windows app: time spent on goals turns into floors of a city.

Product OwnerProject ManagerWindowsGame mechanics
ProblemShow accumulated progress on long goals.
ResultWorking version: timer, city, coins, day streak.
Problem
Timers count hours but do not show the accumulated result of a long goal.
Role
Product Owner and Project Manager. Product brief, mechanics, release priorities, interface requirements. Built with Claude.
What I did
  1. Mechanics: one session adds a floor, floor height is proportional to time.
  2. 3 directions: Work, Development, Entertainment, plus custom ones.
  3. Coins for floors, leisure buildings bought with coins.
  4. A building never closes: the goal is only a marker, a skill can keep growing.
  5. Frameless widget window of fixed size.
Result
3directions
3sections: timer, city, settings
1coin economy
  • Working Windows version: timer, city, settings.
